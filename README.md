# Secure Corporate IT Infrastructure & AWS Security

A hands-on IT infrastructure and cybersecurity project.

## Scenario

Designing a secure corporate IT environment for NovaTech Solutions,
a fictional technology company with 50 employees.

## Project Areas

- Enterprise Network Security
- AWS Cloud Security
- Identity and Access Management
- Endpoint Security
- Security Risk Assessment
- Security Testing and Documentation

## Technologies

Cisco Packet Tracer, AWS, Microsoft Entra ID,
Microsoft Defender, pfSense, Terraform, GitHub.
