# NovaTech Solutions - Business and Security Requirements

## 1. Business Requirements

BR-01: Employees must securely access company resources.

BR-02: IT administrators must manage employee accounts and devices.

BR-03: Employees must only access resources required for their jobs.

BR-04: Guest users must have internet access without accessing internal company systems.

BR-05: The company must securely store and manage cloud resources.

BR-06: Security activities must be documented and monitored.

## 2. Security Requirements

SR-01: Multi-factor authentication (MFA) must be enabled for privileged accounts.

SR-02: Access permissions must follow the principle of least privilege.

SR-03: Corporate networks must be separated by department or security function.

SR-04: Firewall rules must restrict unauthorised network traffic.

SR-05: AWS resources must use secure access configurations.

SR-06: Cloud activity must be logged and monitored.

SR-07: Endpoint devices must follow defined security policies.

SR-08: Security risks must be identified, assessed, and documented.

## 3. User Groups

| User Group | Access Requirements |
|---|---|
| HR | HR-related resources |
| Finance | Financial resources |
| IT Administrators | Infrastructure administration |
| Engineering | Development resources |
| Sales | Sales-related resources |
| Guests | Internet access only |

## 4. Security Principles

- Least privilege
- Defence in depth
- Network segmentation
- Multi-factor authentication
- Secure configuration
- Continuous monitoring
- Accountability and auditability
