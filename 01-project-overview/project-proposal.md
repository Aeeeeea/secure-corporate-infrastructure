# Secure Corporate IT Infrastructure & AWS Security

## 1. Project Overview

This project focuses on designing and implementing a secure corporate IT infrastructure for a fictional technology company, NovaTech Solutions.

The company has 50 employees across five departments and requires a secure, reliable, and centrally managed IT environment.

## 2. Problem Statement

The company faces potential security risks, including:
- Weak user authentication.
- Unauthorised access to company resources.
- Poor network segmentation.
- Inadequate endpoint protection.
- Misconfigured cloud resources.
- Insufficient security monitoring and logging.

These weaknesses could lead to data breaches, service disruptions, and unauthorised access to sensitive company information.

## 3. Project Objectives

1. Design a segmented corporate network.
2. Establish secure identity and access management.
3. Develop endpoint security policies.
4. Design a secure AWS cloud environment.
5. Implement cloud activity monitoring and logging.
6. Conduct a security risk assessment.
7. Document security configurations and testing results.

## 4. Project Scope

The project covers:
- Corporate network architecture.
- Firewall and network access policies.
- AWS IAM and cloud infrastructure security.
- Identity and authentication security.
- Endpoint security management design.
- Security monitoring and risk assessment.

## 5. Expected Outcomes

- A documented corporate network architecture.
- A secure AWS architecture.
- Defined identity and access policies.
- Endpoint protection recommendations.
- A security risk register.
- Security testing and implementation documentation.
